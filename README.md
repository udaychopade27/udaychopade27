## 🧑‍💻 About Me

I'm a **DevOps Engineer at Fusionpact Technologies**, with about a year of hands-on experience building and automating cloud infrastructure. I made the switch into DevOps from a **Mechanical Engineering** background, trained through the **AWS re/Start** and **Capgemini ADAPT** programs — and I've been building real, production-shaped projects ever since to sharpen the skills that training started.

I work across the full automation lifecycle:

```
code → build → test → security scan → deploy → monitor
```

Currently based in Buldhana, Maharashtra, India, and open to relocating to Pune on short notice.

- 🔭 Currently building **DockerMind**, an AI-powered DevOps agent
- 🌱 Deepening my skills in Kubernetes (Helm, Ingress, autoscaling), EKS, and DevSecOps pipelines
- 🎓 AWS Certified Cloud Practitioner, plus KodeKloud Engineer certifications in Terraform, Docker, Jenkins & Kubernetes
- 💬 Ask me about CI/CD pipelines, container orchestration, or AWS infrastructure-as-code

## 🚀 Featured Projects

### 🤖 DockerMind — AI-Powered DevOps Agent
A production-grade DevOps automation agent using a master–slave architecture secured with mTLS, JWT auth with RBAC, and a local LLM (Ollama, qwen2.5-coder, tuned for 4GB RAM). Includes a runbook engine plus Slack/Discord notifications for automated ops actions.

### 💹 [nifty-investment-assistant](https://github.com/udaychopade27/nifty-investment-assistant) — ETF Investment Tracker
React + Vite frontend with a FastAPI backend for tracking a diversified NIFTY ETF portfolio, with a Portfolio Analytics module (XIRR, SIP projection, backtesting). Shipped with its own GitHub Actions CI/CD pipeline — including GHCR image builds, cleanup automation, and cost-optimized caching.

### ☸️ [k8s-projects](https://github.com/udaychopade27/k8s-projects) — Kubernetes 3-Tier Application
A scalable microservice architecture with separate frontend, backend, and database layers deployed on Kubernetes.

### 🔐 [devsecops-project](https://github.com/udaychopade27/devsecops-project) — DevSecOps Infrastructure Setup
Terraform provisions AWS EC2 infrastructure; Ansible configures the servers with Jenkins and Docker — an end-to-end infra-as-code + config-management capstone.

### 📡 [PromethusAndGarafanaSetup](https://github.com/udaychopade27/PromethusAndGarafanaSetup) — Monitoring Stack
Production-grade observability setup with Prometheus, Grafana, exporters, and alert routing.

### 🔄 [cicd-devops-web-app](https://github.com/udaychopade27/cicd-devops-web-app) — Jenkins Declarative Pipeline
Automated, Dockerized deployment pipeline that cut deployment time by 50%.

### 🌩️ [terraform_project](https://github.com/udaychopade27/terraform_project) — AWS Infrastructure as Code
